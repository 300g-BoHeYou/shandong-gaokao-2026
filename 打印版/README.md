# 2026 山东高考 · B5 黑白打印版

本目录是从仓库原始数据（`../data_*.js`、`../scripts/catalog_tree.json`）生成打印版 PDF 的独立工具与成品，不参与网站构建，也与仓库其他文件互不影响。

## 成品

| 文件 | 说明 |
|---|---|
| `2026山东高考打印版.pdf` | **391 页**，B5（176×250mm），纯黑白，约 3.8 MB，矢量文字可搜索 |

标题：**2026年山东高考投档数据与专业排名**（单独占第 1 页，无副标题）

### 页面结构

| 页 | 内容 |
|---|---|

| 2 | 目录 |
| 3 | 说明（本册内容 / 数据来源与口径 / 阅读说明 / 免责声明） |
| 4–5 | **第一部分　2026年一分一段表** — 548 行，6 栏，带表格框线，**每栏顶部重复表头**（分数 / 本段 / 累计位次） |

每部分首页顶部有一条大标题通栏（`第一部分　……`），该页不再重复页眉；其余各页页眉为部分名，
投档表页眉右侧另标出该页位次范围。

### 投档表版式

```
┌────────────────────────────────────────────┬─────┬────────┐
│ 清华大学  工科试验班  [高校专项计划]        │ 693 │    119 │
│   测控技术与仪器(#3)  材料科学与工程(#3)    │     │        │
│   生物医学工程(#2)                          │     │        │
├────────────────────────────────────────────┼─────┼────────┤
│ 北京大学  理科试验班类                      │ 691 │    146 │
│   （在本大类内任选：理科任选）              │     │        │
└────────────────────────────────────────────┴─────┴────────┘
```

- 按最低位次升序排列；表格最右两列依次为最低分、最低位次
- 括号内为该校该专业在软科 2026 的**全国名次**；软科未上榜 / 特色专业 / 该校未被软科收录时不标注
- 专业类招生的志愿类，其下缩进列出**该校该专业类实际开设**的具体专业（软科收录 ∪ 2026 投档直接招生 ∪ 试验班人工查证口径）
- 特殊招生类型以 `[中外合作办学]`、`[地方专项计划]`、`[高校专项计划]` 标出；普通类不标注
- 选科要求与备注未收录

### 一分一段表版式

6 栏，每栏顶部重复表头，整表带框线（分数 / 本段人数 / 累计位次），按分数降序排列。

## 重新生成

依赖：Python 3 + `reportlab` + `fontTools`（预览还需 `matplotlib`）。字体取系统 `C:\Windows\Fonts\simsun.ttc` / `simhei.ttf`。

```bash
cd 打印版
python make_print_pdf.py              # 输出 2026山东高考打印版.pdf
python make_print_pdf.py --preview    # 同时导出抽样页 PNG 到 ./预览/
python qa_layout.py                   # 排版自检：逐行核对是否有文字越过栏边界
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `print_pdf_core.py` | 排版引擎：字形宽度测量（fontTools）、折行、分栏分页、重复表头、部分大标题、绘制指令、reportlab 输出、matplotlib 预览后端 |
| `make_print_pdf.py` | 各章节内容构建与版式参数（标题、字号、列宽、表格列比例） |
| `qa_layout.py` | 自检脚本，输出 `qa.txt` |
| `预览/` | 抽样页 PNG（标题页、目录、说明、各部分首页与末页），便于不开 PDF 阅读器快速核对 |

## 版式参数速查

集中在 `make_print_pdf.py` 顶部，按需调整：

```python
TITLE = '2026年山东高考投档数据与专业排名'   # 标题页文字
BIG_FEN / BIG_CAT / BIG_RK / BIG_TD          # 四部分首页的大标题
SEC_FEN / SEC_CAT / SEC_RK / SEC_TD          # 各部分的页眉文字
TD_NAME = 7.6     # 投档表 院校名/专业类名
RK_TOP = 50       # 软科每专业列出名次上限
FEN_C1, FEN_C2    # 一分一段表三个单元格的分界
TD_COLW / TD_NAME_W / TD_SCORE_W / TD_RANK_W   # 投档表表格列宽
TD_ROWPAD = 0.45  # 投档表行内上下留白（影响总页数最直接）
```

分页由 `print_pdf_core.py` 按精确字形宽度计算，不存在截断或溢出。

## 数据口径提醒

投档表中的「专业类包含专业」为**推断或人工查证口径**，可能与院校当年实际招生专业不完全一致；软科「未上榜」不能作为该校未开设该专业的依据。一切以山东省教育招生考试院及各院校官方公布信息为准。
