# 山东 2026 高考志愿参考 · 2027 届参考版

> 把 2026 年山东投档数据与软科 2026 专业排名整理成可筛选、可对比的交互页面，供 2027 届考生了解各**志愿类**的录取分数/位次、所包含专业及其软科排名。

**🌐 在线使用**：https://sdgk.pages.dev （Cloudflare Pages）— 页面顶部可切换：
- **一批次（常规批）**：`index.html`（23,853 个志愿类查询）
- **强基计划**：`qiangji.html`（39 校政策/专业/校考模式）
- 综合评价：后续加入

**📂 本地使用**：双击仓库根目录的 `index.html` 即可（Chrome / Edge / Firefox 均可，纯前端、无依赖、无需联网）。

**🐙 反馈与贡献**：https://github.com/300g-BoHeYou/shandong-gaokao-2026 （欢迎提 Issue / PR）

> 山东志愿的单位是「**志愿类**」＝ 一所高校的一个或多个专业（最多填报 96 个），**不同于**其他省份的「专业组」。

## 功能一览

| 功能 | 说明 |
|---|---|
| 意向专业筛选 | **按《本科专业目录(2026)》三级结构选择**：门类 → 专业类 → 专业。勾选**整类会同时选中类内全部专业**；类内只选一部分时类名呈**半选状态**，再次点击该复选框可全选 / 全不选（门类同理）。选中项以 chips 显示，可展开查看类内专业、可单独 × 取消；含该类任一专业即命中；**所选专业覆盖某大类全部专业时不再显示"大类招生"警示**；可切换「仅直接招生」 |
| 我的选科 | 从物理/化学/生物/政治/历史/地理选择自己的选科（3+3，最多 3 科）：未填→不筛选；只选 1~2 科→缺科模糊匹配并红色标记"缺：××"；选满 3 科→精确匹配 |
| 分数↔位次 | 第①步双向换算（2026 一分一段表，含同分人数），可一键"填入冲稳保位次" |
| 冲稳保判断 | 输入预估位次 + 可调阈值，自动标注 冲/稳/保/差距大 |
| 软科排名展示 | 每个志愿类列出所含专业的软科状态：`#名次`（上榜）、`未上榜`（前50%外）、`特色专业`（软科不排名）、`未排名`（不在838个发布专业内）；展开「排名明细与说明」可看全国上榜数，**点击专业名直达软科官网该专业排名页** |
| 试验班查证 | 312 个试验班志愿类已按院校官网招生专业一览表人工查证：249 个列出具体包含专业（含软科排名、可被意向专业命中），16 个标注「任选」，47 个待补 |
| 大类提醒 | 「××类」志愿类**按该校实际开设专业筛减**后列出包含专业（软科收录/2026投档/试验班查证口径，如清华计算机类仅显示实际开设的 2 个专业而非目录 19 个）；含意向专业时黄条提醒还包含的其他专业 |
| 备注拆分去重 | 志愿类名括号内多条备注拆分为多个徽章；与招生类型徽章重复的自动去重 |
| 收藏 / CSV 导出 / 打印 | 本地收藏对比、导出筛选结果到 Excel、Ctrl+P 打印 |
| 输入校验 | 所有数字输入仅接受正整数，拒绝 0、负数、小数及超范围值 |

### 强基计划页（`qiangji.html`）

| 功能 | 说明 |
|---|---|
| 两种校考模式解读 | 出分后校考（28 所：可放弃、避免锁档）vs 出分前校考（11 所：高考分略低者也有机会、锁档性强） |
| 院校强基信息 | 39 所高校：校考模式、校考时间、**入围比例（39 校齐全，取自官方简章）**、入围方式、入围成绩计算、校考形式、竞赛破格政策、**报名时间（阳光高考平台精确时间）**、2026 政策要点 |
| 官方简章链接 | 每校附**阳光高考·强基计划报名平台**链接（`bm.chsi.com.cn/jcxkzs/sch/<校代码>`）；其中 15 校另附**学校本科招生网简章原文**直链 |
| 专业类与考查科目 | 每校强基专业类（含"数理基础科学"等与目录无关的类名）；**专业类下的每个专业单独成行**，各自标注软科2026排名、该校该专业的普通批参考分/位次；仅面试院校统一标注「无笔试」；带方向括号的（如"汉语言文学（古文字学方向）"）以去括号名作为专业，专业类名称仍保留官方原名 |
| 专业名称校验 | 逐条比对《本科专业目录（2026年）》：明显错字自动修正（如"土木水利与海洋工程"→"土木、水利与海洋工程"）；目录中查无此名或名称疑似有误的给「⚠ 待核」提示；**软科"未上榜"不作为"该校已开设"的依据**，简章未提及、一批次无直接招生的一并标出待核 |
| 分专业普通批参考分 | 显示为 **分数（排名）**：优先取该校**同名专业**志愿类；若该校按大类/试验班招生，则取**含该专业的大类**（含已人工查证的试验班，清华按文/理试验班）分数；候选中取**最低分**，并排除专项计划、中外合作办学、分校/校区及定向/预读等特殊计划；并注明参考口径（同名专业/大类/试验班） |
| 筛选 | 按**三级目录选择专业**（门类/专业类/专业，可整类选择，选中项 chips 可展开与取消）、校考模式（出分前/出分后）、校考形式（笔试/仅面试）、院校名 |
| 数据来源 | 各校 2026 年强基简章原文：阳光高考强基报名平台内联简章（24 校）、各校本科招生网/省阳光高考平台（15 校）；抓取与抽取脚本见 `scripts/crawl_qiangji*.py`、`scripts/extract_*.py`；人工查证明细见 `强基查证清单_官方核对.xlsx` |

## 数据来源与口径

1. **投档表**：山东省 2026 年普通类常规批第 1 次志愿投档表，共 **23,853** 个志愿类（最低分/最低位次/选科要求/招生类型）。
2. **软科 2026 中国大学专业排名**：发布 **838** 个专业（依据教育部《普通高等学校本科专业目录（2026年）》，与目录 2026 版完全一致）；仅上榜前 50% 院校；开设 <4 校的专业为「特色专业」，只发布开设名单、不计算排名；中国科学院大学、中国社会科学院大学及军事院校未纳入。
3. **《普通高等学校本科专业目录（2026年）》**：用于专业名校验；大类→包含专业**仅以目录定位专业范围，再按该校实际开设筛减**（"该校实际开设"＝软科收录该专业 ∪ 2026 投档表直接招生 ∪ 试验班查证），避免把目录全集误作学校实际开设；该校无软科收录时回退目录全集并标注「目录口径」；**软科未收录院校的大类行已人工查证**（国防科技大学 5 行、中国社会科学院大学 1 行，标注「大类招生·已查证」；重庆外语外事学院 1 行待查证，清单见 `大类查证清单（剩余未收录）.xlsx`）。
4. **一分一段表**：2026 年分数↔位次换算。
5. **试验班查证**：312 个试验班志愿类的包含专业来自各院校官网 2026 年招生信息，人工查证整理（明细见 `试验班查证清单.xlsx`）。
6. 威海/深圳/医学部等校区沿用**校本部**软科排名口径（页面有徽章标注）。

## 构建与自测（维护者）

```bash
# 1) 解析目录（首次或目录更新后）
python scripts/parse_catalog.py

# 2) 合并全部人工查证（更新过查证清单后；试验班+大类统一到一个文件）
python scripts/merge_manual_check.py

# 3) 生成站点数据（需要 pandas + openpyxl）
python scripts/build_data.py

# 4) 生成/更新强基查证表与强基数据（更新过强基查证清单后，需先改造 make_qiangji_sheet.py 读取填好的表）
python scripts/make_qiangji_sheet.py

# 5) 自测（需要 node）
node scripts/verify_app.js     # 一批次逻辑断言
node scripts/smoke_dom.js      # 一批次渲染冒烟
node scripts/check_qiangji.js  # 强基数据/渲染/筛选/页面元素
node scripts/check_tags.js     # HTML 标签配平
node scripts/check_ids.js      # 元素 id 一致性
```

## 已知限制与免责

- 本工具基于 **2026 年**录取数据，仅供 **2027 届**考生了解院校专业层级与分数/位次量级，**不是** 2027 年预测。
- 位次每年随考生人数、招生计划、选科政策变化，「冲稳保」仅为粗略参考；选科要求为 2026 年口径，2027 年以省考试院公布为准。
- 大类包含专业已按"该校实际开设"筛减（软科收录∪投档直接∪查证），但仍可能遗漏软科未上榜的专业，以院校当年简章为准；软科未收录的院校（如军校/民办）回退目录全集并标注。**大类/试验班包含专业均属推断或人工查证口径，可能不够可靠，网页顶部有醒目提醒。**
- **强基计划页**数据整理自各校 2026 年强基简章及公开报道：校考模式/时间/形式/竞赛破格等已按公开信息预填，入围比例、专业类包含专业等字段标注「待查证」，以院校当年简章为准。强基录取后锁档（不再参加后续批次录取）。
- 一切以山东省教育招生考试院及各院校官方公布信息为准，本工具不构成填报建议。
